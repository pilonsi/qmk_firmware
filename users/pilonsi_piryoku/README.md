# My QMK Layout
This is my personal 36-key layout, it is a modified version of the wonderful [Miryoku](https://github.com/manna-harbour/miryoku/) layout by Manna Harbour.

![Layout Reference](https://i.imgur.com/kKe5ndU.png)

The layout is intended to be used with the US-Intl. keymap.

## Main differences
While I love Miryoku, I did have a few issues with it, all of which I have attempted to correct here to make it better suit my needs:

 - Removed auto-shift. I did not use this feature and I often triggered it unintentionally.
 - Removed MOUSE layer which I did not use and replaced it with a Catalan / Spanish / French layer.
 - Added one-hand shortcuts to the MEDIA layer left hand, now the MESH layer.
 - Removed configurability. This layout is (at least for now) QWERTY + Vi nav only. Easier to mantain, I may start adding back configuration options when I eventually take the plunge and move out from QWERTY.

## Future goals
This is still a work in progress layout. I plan on adding the following features before considering it complete:

 - Unicode support for languages other than English. I usually also type in Catalan and other languages which require additional symbols which are not available in the US-Intl. keyboard.
