# My QMK Layout
This is my personal 36-key layout, it is a modified version of the wonderful [Miryoku](https://github.com/manna-harbour/miryoku/) layout by Manna Harbour.

![Layout Reference](https://i.imgur.com/3TrM1YD.png)

## Main differences
While I love Miryoku, I did have a few issues with it, all of which I have attempted to correct here to make it better suit my needs:

 - Removed auto-shift. I did not use this feature and I often triggered it unintentionally.
 - Removed MOUSE and SYM layers. Mouse I did not use and I prefer to free up a thumb by accessing symbols through NUM + Shift.
 - Swapped BUTTON layer with a new Short layer (One hand shortcuts) which better suits my needs.
 - Removed configurability. This layout is (at least for now) QWERTY + Vi nav only. Easier to mantain, I may start adding configuration options when I eventually take the plunge and move out from QWERTY.
 - Prioritized the outer thumb keys and therefore making this a 34-key layout with optional 36-key features.

## Future goals
This is still a work in progress layout. I plan on adding the following features before considering it complete:

 - Unicode support for languages other than English. I usually also type in Catalan and other languages which require additional symbols. This will take one of the freed MOUSE/SYM layers.
 - Test and make options for 34-key mode.
