# Pilonsi layout version 14.2
This is my personal 36-key layout, inspired by [Miryoku](https://github.com/manna-harbour/miryoku).

It is intended to be used with the US layout. To input catalan characters it makes use of
the [QMK Unicode feature](https://docs.qmk.fm/features/unicode#input-modes). It also includes
a set of one-handed shortcuts in the opposite side of the Nav layer. Both the unicode input and
the shortcuts require the Host OS setting to be properly set up for your machine.

To cycle through the different OS modes (Win, MacOS, Other *nixes) use the Mode key in
the configuration layer. The mode key cycles but does not save to EEPROM, to save
unnecessary writes. If you want to make the current selection permanent use the Save
key.
